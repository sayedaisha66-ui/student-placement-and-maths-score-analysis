Student Placement and Mathematics Performance Analysis
This project explores a dataset of 105 students, comparing their mathematics performance and GPA with recorded placement outcomes: fail, inland, and foreign.
I used MySQL to query and summarize the data, then built a Power BI report to visualize the results. The analysis includes average math scores by placement group, subject-level comparisons, and patterns across student groups.
The findings describe associations in this dataset; they do not show why a student received a placement outcome or establish cause and effect. The dataset does not include a direct measure of students’ interest in mathematics.
